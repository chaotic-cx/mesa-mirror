Mesa 26.2.7 Release Notes / 2026-11-11
======================================

Mesa 26.2.7 is a bug fix release which fixes bugs found since the 26.2.6 release.

Mesa 26.2.7 implements the OpenGL 4.6 API, but the version reported by
glGetString(GL_VERSION) or glGetIntegerv(GL_MAJOR_VERSION) /
glGetIntegerv(GL_MINOR_VERSION) depends on the particular driver being used.
Some drivers don't support all the features required in OpenGL 4.6. OpenGL
4.6 is **only** available if requested at context creation.
Compatibility contexts may report a lower version depending on each driver.

Mesa 26.2.7 implements the OpenCL 3.1 API, but the version reported by
the CL_DEVICE_VERSION, CL_DEVICE_NUMERIC_VERSION and CL_DEVICE_OPENCL_C_ALL_VERSIONS
clGetDeviceInfo queries depends on the particular driver being used.

Mesa 26.2.7 implements the Vulkan 1.4 API, but the version reported by
the apiVersion property of the VkPhysicalDeviceProperties struct
depends on the particular driver being used.

Bug fixes
---------

- # va: H.264 encode spins forever in vaRenderPicture on some packed SPS headers (vl_rbsp misreads emulation prevention bytes)
- Asahi OpenCL compiler packing assertion failed
- Confidential issue #16794
- Fails to build on macOS < 10.12
- LLVM 23, riscv64, compile error gallium/auxiliary/gallivm/lp_bld_init_orc.cpp (API change?)
- Last Of Us Part 2 Remastered has glitches on hair strands - since Mesa 26.0.1
- RadeonSI syncrhonization/barrier issue with Clear+Dispatch (Repro included)
- V3D: Labwc fails to allocate GBM buffers wider than 4096 pixels unless non-MSAA texture size limit is enabled
- VC4: Kodi on Pi 3: DRM PRIME / V4L2 fails after Mesa 26.2.6 with avfilter_graph_config: Function not implemented (-38)
- Windows ARM memory-leak
- [ANV] Flickering black blocks in Project Wingman
- [OpenMW] Certain shaders cause visual corruption at the bottom of the screen when anti-aliasing is enabled, possibly Z-buffer related
- ac/radv/radeonsi: PS restricted to 2 of 6 CUs on Rembrandt 660M with fully harvested SA0 (~50% graphics perf loss)
- anv: compute shader writes to a storage image are partly lost after a render pass cleared the image earlier in the same command buffer on Intel LNL
- asahi: 64-bit multiply of a sign-extended sub-32-bit value produces wrong result
- llvmpipe/lavapipe: freed device memory is never released from the memfd
- radv: PixelInterlockOrderedEXT critical sections of consecutive draws in one subpass are not ordered (Radeon 780M, GFX11)
- radv: VK_EXT_descriptor_heap causes  performance slow down in FSR 4.1 workloads
- rusticl/llvmpipe: heap corruption / SIGSEGV in \`llvmpipe_set_global_binding` when kernels on two queues are released by one \`clWaitForEvents`
- zink/ntv: pack_snorm_2x16 and unpack_snorm_2x16 unimplemented, aborts the process
